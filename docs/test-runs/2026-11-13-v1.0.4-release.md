## Local and runtime acceptance

`npm run check` passes all 264 tests, syntax checks, manifest validation and
staging checks. Final candidate runs use Foundry 13.351 / Node 22.23.2 and
Foundry 14.369 / Node 24.15.0, SocketLib 1.1.4, Playwright 1.63.0 and installed
Microsoft Edge with isolated browser contexts.

Each generation passes 37 GM groups, 13 player groups, 509 positive observations
and 18 expected negative observations. Both formatting regressions, permissions,
concurrent/stale requests, synthetic-Actor identity, distributions and rollback,
item transfers, light/dark themes, keyboard/focus and module disable/reload pass.
The runtime source and diagnostics were not patched to bypass acceptance checks.

Known upstream exceptions: one core `#postNotification` chat-animation error on
v13 and eight on v14; six equipment-journal migration messages on v13. Each run
also contains its deliberate sanitation-fixture `/x` 404. No unclassified
warning, error or deprecation is accepted by the final verifier.

Temporary license copies were removed and ports 33413/33414 released. Sandbox
startup failures remain recorded separately; both authorized retries passed.
Private worlds, logs, screenshots and per-file hashes remain outside the public
repository in `RuntimeTests/releases-hyp3e-4.9.2-2026-11-13/`. Utilities acceptance
is recorded in `utilities/ACCEPTANCE.json`.

## Publication verification

The tag workflow builds from the same allowlist and validates the archive and
checksums. CI ZIP container bytes may differ from the local candidate; every
published payload file must match the exact tested candidate. Public asset and
native-manifest installation results are recorded after publication.
