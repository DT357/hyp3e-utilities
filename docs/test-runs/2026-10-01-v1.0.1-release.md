documentation, then running the release workflow, after the outstanding

## Release Procedure

Run local checks and focused runtime checks on the release-shaped 1.0.1
candidate, commit the reviewed files, push `main`, and push `v1.0.1` to trigger
**Validate and Release**. Its package job reruns checks, creates the allowlisted
archive, and verifies checksums. Its release job publishes that same artifact.
Verify the completed workflow and the published assets afterward.

The separate **Publish Release to Foundry VTT** workflow is not part of this
GitHub release operation.
