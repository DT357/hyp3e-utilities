# FND-005 — Establish shared ApplicationV2 shells

Status: `DONE`

Completed: 2026-08-14

## Implemented outcome

Added factory-created ApplicationV2 classes, shared template paths, localized
foundation templates, template preloading, and a module-scoped CSS namespace.
The factory keeps Node tests independent of Foundry globals.

## Files changed

- `module/apps/foundation-applications.mjs`: Implements the base and three menu
  application classes.
- `templates/`: Adds the shared shell, reset, permissions, and party placeholder
  templates.
- `lang/en.json`: Adds foundation UI and notice strings.
- `styles/hyp3e-utilities.css`: Adds scoped shell and form styling.
- `tests/unit/application-shell.test.mjs`: Verifies application contracts and
  template preloading.

## Verification

- Automated shell tests passed.
- All four application classes rendered localized content and closed cleanly
  in Foundry 13.351 and 14.365.

## Known limitations and follow-up

- The open-party-sheet menu intentionally renders a placeholder until PAR-005.
- The reset-HUD menu becomes user-visible functionality when HUD-006 adds
  position persistence.
