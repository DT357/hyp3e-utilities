# PAR-005 — Implement the singleton Party Sheet application

Status: `DONE`

Completed: 2026-08-15

## Implemented outcome

The placeholder has been replaced by the production Party Sheet ApplicationV2
shell. It renders all six localized product tabs, displays the current Party
State revision and the current user's edit status, and switches tabs through
Foundry's native action-handler contract.

Constructing or opening the sheet while it already exists returns the same
application. Rendering brings that instance forward and refreshes its context.
The sheet subscribes once to namespaced Party State and permission hooks,
rerenders for external updates, removes both subscriptions on close, and then
allows a clean replacement instance. The existing Settings menu points
directly to this singleton class, so it remains a working open control for GMs
and authorized or read-only users.

## Files changed

- `module/apps/foundation-applications.mjs`: Replaces the placeholder with the
  focused singleton, tab actions, permission/state context, and lifecycle
  cleanup.
- `templates/party-sheet.hbs`: Adds the localized six-tab shell and revision/
  access status. The obsolete placeholder template was removed.
- `styles/hyp3e-utilities.css`: Adds scoped Party Sheet shell layout.
- `module/core/constants.mjs`, `module/settings/settings.mjs`, and
  `module/core/bootstrap.mjs`: Add the permission-update hook, production
  template path, dependencies, and provider wiring.
- `lang/en.json`: Localizes the shell, access state, navigation, and six tabs.
- `tests/unit/application-shell.test.mjs` and `tests/unit/settings.test.mjs`:
  Cover singleton identity, focus/rerender, tab actions, context, external
  refresh, close cleanup, replacement, and permission hook emission.
- `tests/foundry/diagnostics/diagnostics.mjs`: Adds the production ApplicationV2
  lifecycle and tab-action gate.

## Verification

- `npm run check` passed with 80 automated tests, syntax checks, localization
  checks, and manifest validation.
- Foundry 13.351 with `hyp3e` 4.0.3 and Foundry 14.365 with the official
  `hyp3e` dev 4.1.0 system each rendered one localized six-tab window, reused
  it on reopen, switched tabs, rerendered on an external state hook, removed
  the listener on close, and rendered a new replacement instance.
- The first live run exposed an ApplicationV2 action-signature mismatch in
  both generations. The handler now reads Foundry's second `target` argument;
  the corrected final runs passed every assertion with no diagnostic error.
