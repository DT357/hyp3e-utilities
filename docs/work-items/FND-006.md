# FND-006 — Guard unsupported runtime environments

Status: `DONE`

Completed: 2026-08-14

## Implemented outcome

Added explicit Foundry 13–14, `hyp3e`, and minimum `hyp3e` 4.0.3 runtime
checks. Unsupported environments log concrete reasons and do not register the
ready hook or initialize feature services.

## Files changed

- `module/core/bootstrap.mjs`: Evaluates compatibility before foundation setup.
- `module/hyp3e-utilities.mjs`: Wires the production lifecycle and logger.
- `tests/unit/compatibility.test.mjs`: Covers supported matrices, each rejection
  reason, hook suppression, and dependency-first lifecycle ordering.

## Verification

- Compatibility tests passed, including a non-`hyp3e` guard case.
- Foundry 13.351 / `hyp3e` 4.0.3 and Foundry 14.365 / `hyp3e` 4.1.0 both
  accepted the environment and published the API without module warnings.

## Known limitations and follow-up

- New Foundry or `hyp3e` versions remain unsupported until validated and the
  declared range is deliberately updated.
