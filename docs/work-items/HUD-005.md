# HUD-005 — Render the NPC Action HUD overlay

Status: `DONE`

Completed: 2026-08-14

## Implemented outcome

Added the visible GM-facing NPC Action HUD. It subscribes to the HUD-004
selection controller, maintains one stable DOM overlay, removes it immediately
for a hidden model, and prevents an older asynchronous template render from
replacing a newer selection.

Each token row displays the token name, optional NPC subtype, clamped current
and maximum HP bar, AC, DR, movement, and morale or a missing-morale indicator.
The Actor button resolves the token UUID first and opens that exact Actor sheet,
preserving synthetic unlinked-token context.

The header provides Reaction and Morale actions plus the approved compact
five-category save selector and Save button. These controls consume the exact
HUD-004 roll candidates and reuse HUD-001 through HUD-003 planning and chat
services. Partial skips and failures produce one localized summary notice.

## Files changed

- `module/hud/npc-action-hud.mjs`: Builds safe display context, renders and
  removes the overlay, delegates controls, opens exact token Actor sheets, and
  dispatches existing roll/chat services.
- `templates/npc-action-hud.hbs`: Defines the localized overlay, controls,
  token rows, statistics, health visualization, and missing-morale state.
- `styles/hyp3e-utilities.css`: Adds the fixed desktop overlay, scrollable
  target list, clamped health bars, long-name ellipsis, and responsive row
  layouts.
- `module/core/constants.mjs` and `module/core/bootstrap.mjs`: Register,
  preload, publish, and start the overlay.
- `lang/en.json`: Localizes HUD labels, save options, and action reports.
- `tests/unit/npc-action-hud.test.mjs`: Covers HP clamping, five saves, stable
  overlay lifecycle, planner/chat reuse, exact Actor-sheet resolution, partial
  notices, and stale-render rejection.
- `tests/foundry/diagnostics/diagnostics.mjs`: Exercises real template output,
  canvas rows, Actor updates, UI clicks, sheets, chat messages, and removal.

- `npm run check` passed with 46 automated tests.

  disposable data root on port 33354.
- Foundry 14.365 / official `hyp3e` dev 4.1.0 passed the same assertions in a
  disposable data root on port 33355.
- Each live run rendered two distinct token rows, all five save choices,
  clamped HP widths, AC/DR/movement, and one missing-morale state. The exact
  synthetic Actor sheet opened from its token row.

  messages: two reaction, two save, and one morale. The second morale target
  was skipped and reported once because it had no numeric target.

  bars, responsive statistics, and correct long-name ellipsis. Foundry's own
  minimum-window notice overlapped the fixed top position but did not affect
  HUD behavior; HUD-006 will make the overlay movable and viewport-clamped.
