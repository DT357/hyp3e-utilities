# XP-002 - Party Sheet XP preview

Status: `DONE`

Completed: 2026-08-15

## Implemented outcome

The Party Sheet Overview now gives GMs a write-free XP allocation workflow.
All tracked members and followers are shown in state order, positive-share
recipients default to selected, and missing references stay visible but cannot
participate. The preview reports each selected recipient's base XP, signed
adjustment, final allocation, and explicit writeback status, plus total shares
and undistributed base XP.

The preview service resolves authoritative world Actors and passes only their
hyp3e type, current XP bonus, and saved Party Sheet share into the XP-001
calculator. The application renders the calculator's returned distribution
objects directly. Local total and selection drafts survive external rerenders;
a Party Sheet revision change marks the preview stale for the later
confirmation gate.

## Files changed

- `module/party/party-xp-preview.mjs`: Adapt Party Sheet state and hyp3e Actors

  types so missing references can never be mistaken for characters.
- `IMPLEMENTATION-PLAN.md`: Mark XP-002 complete.
