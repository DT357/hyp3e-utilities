# HUD-008 — Complete the HUD accessibility and error audit

Status: `DONE`

Completed: 2026-08-14

## Implemented outcome

The NPC Action HUD now exposes native keyboard-operable controls, a labelled
region, an announced selection count, localized drag and Actor-sheet labels,
and visible focus indicators. All five saving-throw categories remain visible;
categories without any numeric target are disabled. The active save action and
morale action are disabled when the selected NPCs cannot perform them, while
reaction remains available for every visible NPC row.

Unavailable roll batches are rejected before chat creation. UI action failures
and position-persistence failures show localized GM notices and retain detailed
console logging. Notification services are resolved at use time so notices work
when Foundry initializes `ui` after module lifecycle registration.

## Files changed

- `module/hud/npc-selection.mjs`: Adds immutable prepared save targets to HUD
  rows.
- `module/hud/npc-action-hud.mjs`: Computes save availability, rejects empty
  batches, and resolves runtime notification services safely.
- `templates/npc-action-hud.hbs`: Adds region, announcement, labels, and
  unavailable-control semantics.
- `styles/hyp3e-utilities.css`: Adds visible keyboard focus treatment.
- `lang/en.json`: Adds HUD accessibility, unavailable-state, and persistence
  error messages.
- `tests/unit/npc-action-hud.test.mjs` and `tests/unit/localization.test.mjs`:
  Cover availability, late Foundry UI initialization, template semantics, and
  localization completeness.
- `tests/foundry/diagnostics/diagnostics.mjs`: Adds the production HUD-008 gate.
