# FND-004 — Bootstrap authenticated SocketLib transport

Status: `DONE`

Completed: 2026-08-14

## Implemented outcome

Declared SocketLib v1.1.4 as a required dependency and added an idempotent
transport bootstrap. The transport exposes only registered operation names,
uses `this.socketdata.userId` for caller identity, checks the current active GM
on every call, and reports unavailable dependency or GM states clearly.

## Files changed

- `module.json`: Declares socket use and the required SocketLib relationship.
- `module/socket/socket-transport.mjs`: Implements bootstrap and authenticated
  `ping` transport.
- `module/core/bootstrap.mjs`: Handles dependency-first and module lifecycle
  ordering.
- `tests/unit/socket-transport.test.mjs`: Covers identity, missing dependency,
  absent GM, changed GM, named operations, and idempotent initialization.
- `THIRD_PARTY_NOTICES.md`: Records the runtime dependency and its MIT license.

## Verification

- Automated transport tests passed.
- Authenticated active-GM round trips passed in Foundry 13.351 and 14.365.
- SocketLib v1.1.4 owns selection among connected active GMs; the module does
  not cache a selected GM.

## Known limitations and follow-up

- `ping` is the only operation in this foundation batch. PAR-002 and PAR-004
  add mutation schemas, authorization, revisions, and idempotency.
