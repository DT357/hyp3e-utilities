# PKG-001 — Prepare the 1.0.0 release artifact and workflow

## Implemented outcome

Prepared Hyp3e Utilities 1.0.0 as a validated, unpublished release candidate.
The release metadata, canonical payload, user-facing changelog, checksums, and
GitHub Actions handoff now form one fail-closed pipeline.

The workflow validates and retains the exact bytes that an authorized version
tag would publish. Its release job cannot run for a branch or pull request and
cannot rebuild or substitute the candidate.
