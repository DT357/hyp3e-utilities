# HUD-001 — Implement reaction rules and batch planning

Status: `DONE`

Completed: 2026-08-14

## Implemented outcome

Added the seven-band Hyperborea reaction lookup and an immutable batch planner
that emits one unmodified `2d6` instruction for every selected NPC token
instance. Linked duplicates retain separate token identities and non-NPC
targets are reported as skipped.

Neutral outcomes carry a reroll indicator for later chat output but do not
automatically schedule another roll, preserving the approved one-roll-per-NPC
action behavior.

## Files changed

- `module/hud/reaction-table.mjs`: Defines reaction boundaries and outcomes.
- `module/hud/npc-rolls.mjs`: Builds token-aware reaction batches.
- `tests/unit/reaction-table.test.mjs`: Covers totals below zero through above
  12, neutral reroll metadata, empty selection, duplicate Actor tokens, and
  non-NPC targets.
- `tests/foundry/diagnostics/diagnostics.mjs`: Exercises the production planner
  against live Actors.
