# SUP-001 — Add validated manual supply fields

Status: `DONE`

Completed: 2026-08-15

## Implemented outcome

The Party Sheet Supplies tab now exposes manual counts for torches, lanterns,
oil, and rations. Editors receive native whole-number inputs and one atomic
Save Supplies action; read-only users receive the same saved values as output.
The module does not inspect, infer, or consume Actor or treasury inventory.

Each value is blank or a canonical non-negative safe whole-number string.
Named-operation validation requires all four keys and rejects negative,
fractional, non-numeric, oversized, missing, or unknown values without a Party
State revision. Legacy state normalization preserves blanks, canonicalizes
valid counts, and clears invalid values.

The four inputs form one local draft with a captured base revision. External
Party State changes preserve the draft and display the shared stale warning;
the stale save is rejected at its original revision, and explicit discard
restores authoritative counts.
