# XP-001 - Pure XP allocation

Status: `DONE`

Completed: 2026-08-15

## Implemented outcome

The XP calculator is a pure function that normalizes the entered pool to a
non-negative safe whole number and shares to the Party Sheet's quarter-share
increments. It allocates each selected positive share independently with floor
division, reports the undistributed base remainder, and uses exact integer
arithmetic for totals through `Number.MAX_SAFE_INTEGER`.

Character awards apply the signed hyp3e XP percentage after base allocation by
flooring the final adjusted award to a non-negative whole number. NPC shares
remain in the divisor and consume their base allocation, but ignore XP bonuses
and expose a zero persistent award so later transaction code cannot mistake
their encounter XP field for a destination.
