# ITM-005 — Transfer UI entry points

Status: `DONE`

Completed: 2026-08-15

## Implemented outcome

Supported item transfers now have confirmation-driven entry points on both the
Party Sheet and owned hyp3e character sheets. A character Item can be dropped
on the Party Sheet shared-equipment area or sent with an injected **To Party**
button. A supported Party Treasury row can be dragged onto an owned character
sheet or sent with **Take** after selecting an eligible party character.

Every entry point opens a modal DialogV2 preview naming the Item, source, and
destination and constraining quantity to a positive whole amount on hand.
Closing the dialog performs no operation. Invalid payloads, unsupported Items,
unavailable treasury state, unauthorized Party editors, and unowned character
endpoints are rejected before the dialog; the active-GM operations repeat all
security and freshness validation authoritatively.

Treasury drag data uses a namespaced type and MIME marker so the Actor Sheet
capture handler intercepts only this module's transfer. Character-to-party
drops accept Foundry's public Item drag UUID. Button alternatives make both
directions keyboard-accessible.

Authorized players may not have the private treasury Actor in their local
collection. Reverse UI therefore uses only the authorized snapshot's display
name and expected quantity for confirmation, while the active GM resolves the
real Item from the bound treasury before writing. No private Actor document is
exposed to the client.

## Files changed

- `module/party/item-transfer-ui.mjs`: Adds permission-aware resolution,
  DialogV2 confirmation, native/custom drop parsing, Party destination options,
  Actor Sheet hook decoration, button alternatives, and request routing.
- `module/apps/foundation-applications.mjs`: Adds Party Sheet destination
  context, Take action, treasury drag start, and character Item drop handling.
- `module/core/bootstrap.mjs`: Creates, starts, and exposes the UI controller;
  also aligns ownership-level injection with the existing service contracts.
- `templates/party-sheet.hbs`, `styles/hyp3e-utilities.css`, `lang/en.json`:
  Add the accessible drop zone, destination selector, draggable rows, Take
  controls, styling, help, confirmation, result, and rejection text.
- `tests/unit/item-transfer-ui.test.mjs`: Covers valid drops both ways, hidden
  treasury snapshots, cancellation, invalid payload, denied/unowned users,
  eligible destinations, Actor Sheet controls, and hook lifecycle.
- `tests/unit/application-shell.test.mjs`: Covers Party Sheet context, button,
  drag serialization, and drop routing.
