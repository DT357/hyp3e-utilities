# PAR-007 — Implement the Followers workflow

Status: `DONE`

Completed: 2026-08-15

## Implemented outcome

The Followers tab now accepts durable world `character` and `npc` Actors by
drag/drop. Non-GM editors must own the Actor they add, GMs bypass that Actor
ownership check, and a tracked Actor cannot be both a member and follower.

Follower rows display the shared combat summary plus the hyp3e NPC subtype.
Authorized editors can persist a non-negative whole-GP daily wage and a
non-negative quarter-share value through one GM-authoritative operation.
Read-only users see the same saved employment data without form controls.

Removing a follower clears only its wage, share, and marching-order metadata.
Missing references remain visible with their stored employment values and an
authorized cleanup action; automatic cleanup remains assigned to PAR-010.

  0.75 share, opened the exact Actor sheet, and removed both followers.

  follower reference. All runtime diagnostics completed with no errors.
