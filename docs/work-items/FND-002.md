# FND-002 — Add the hyp3e document adapter

Status: `DONE`

Completed: 2026-08-14

## Implemented outcome

Centralized reads for HP, AC/DR, movement, saves, morale, loyalty, XP, money,
and physical-item quantities. Added explicit write policies and update builders
for character XP and character/treasure money, with NPC writes rejected.

## Files changed

- `module/adapters/hyp3e-adapter.mjs`: Implements the schema boundary.
- `tests/fixtures/hyp3e-documents.mjs`: Supplies minimal synthetic fixtures.
- `tests/unit/hyp3e-adapter.test.mjs`: Covers character, NPC, treasure, linked,
  and synthetic-shaped inputs plus missing values and write policies.

## Verification

- Adapter fixture tests passed in Node.
- Representative documents passed through the production adapter in Foundry
  13.351 / `hyp3e` 4.0.3 and Foundry 14.365 / `hyp3e` 4.1.0.

## Known limitations and follow-up

- The adapter builds updates but does not perform distribution or transfer
  mutations; those belong to the XP, coin, wage, and item work items.
