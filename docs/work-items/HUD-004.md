# HUD-004 — Implement controlled-NPC selection controller

Status: `DONE`

Completed: 2026-08-14

## Implemented outcome

Added a UI-independent controller that observes the live Foundry canvas and
publishes an immutable, deterministic view model for controlled NPC tokens.
The model is available only to a GM in a supported `hyp3e` world while the
canvas is ready and the NPC Action HUD world setting is enabled.

Each controlled token produces its own row keyed by token-document UUID, so
multiple linked tokens for one Actor remain distinct. Rows retain Actor UUIDs
and exact Actor references for later roll actions, including token-scoped
synthetic Actors. Character tokens are filtered, duplicate token UUIDs and
malformed targets are reported as skipped entries, and rows are alphabetized
by token display name.

The controller coalesces hook-driven refreshes, preserves the same view-model
object when its serialized content is unchanged, notifies subscribers only on
meaningful changes, and removes every registered hook on destruction. Its row
contract includes token and Actor identity, NPC subtype, HP, AC/DR, movement,
and optional morale for HUD-005 rendering.

## Files changed

- `module/hud/npc-selection.mjs`: Builds the immutable row model and manages
  selection synchronization, subscribers, roll candidates, and hook cleanup.
- `module/adapters/hyp3e-adapter.mjs`: Adds the verified `system.npcType`
  subtype mapping.
- `module/settings/settings.mjs`: Emits the namespaced setting-change hook for
  immediate HUD enable/disable synchronization.
- `module/core/bootstrap.mjs`: Publishes and starts the controller through the
  production module API.
- `tests/unit/npc-selection.test.mjs`: Covers filtering, linked/unlinked token
  identity, sorting, immutability, stable models, refreshes, gates, deletion,
  canvas teardown, and cleanup.
- `tests/foundry/diagnostics/diagnostics.mjs`: Exercises the production
  controller against real selected tokens and Actor/document hooks.
- Adapter, settings, compatibility, fixture, and test documentation files were
  extended for the new contract.
