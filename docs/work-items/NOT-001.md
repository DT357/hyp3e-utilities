# NOT-001 — Add shared rich-text party and treasure notes

Status: `DONE`

Completed: 2026-08-15

## Implemented outcome

The Party Sheet now exposes one shared Party Notes editor and separate Gems
and Jewelry and Other Treasure editors. All three use Foundry's supported
`HTMLProseMirrorElement` on Foundry 13 and 14. Authorized editors can update
the fields; other users receive the same enriched read-only content.

The fields save together through one strict `party.setNotes` operation and one
Party State revision. The authoritative mutation cleans each value with
Foundry's `foundry.utils.cleanHTML` before any field is assigned, so a failed
cleaning pass cannot partially update state. Enrichment remains a display-only
step and is never persisted.

Local note drafts retain their original base revision. The Party Sheet checks
ProseMirror's own dirty state immediately before an external rerender, which
preserves edits even when the custom element does not bubble an input event.
External changes produce the shared stale warning; stale saves are rejected,
and explicit discard restores authoritative content.

- `module/party/party-notes.mjs`: Adds strict payload validation, atomic HTML
  cleaning, the named mutation, and a read service.
- `module/apps/foundation-applications.mjs`: Mounts supported ProseMirror
  elements, enriches display content, preserves dirty drafts, and implements
  save/discard and stale-revision behavior.
- `module/core/bootstrap.mjs`: Injects Foundry's sanitizer and publishes the
  note service.
- `templates/party-sheet.hbs`: Implements the Treasure and Notes tabs.
- `styles/hyp3e-utilities.css`: Adds responsive editor layout and usable editor
  height.
- `lang/en.json`: Adds note labels, guidance, save actions, and errors.
- `tests/unit/party-notes.test.mjs`: Covers strict validation, atomic cleaning,
  read copies, and dependency checks.
- `tests/unit/application-shell.test.mjs`: Covers supported editor creation,
  enrichment, dirty-state preservation, atomic payloads, stale retention, and
  discard.
- `tests/unit/compatibility.test.mjs`: Confirms note-service publication.
- `tests/foundry/diagnostics/diagnostics.mjs`: Adds repeatable GM/Player
  sanitization, editor, permission, conflict, and persistence assertions.

## Known limitations and follow-up

- Treasure coins and physical inventory remain owned by the managed treasury
  Actor work in Milestone 4; these two fields are descriptive notes only.
- Collaborative ProseMirror editing is disabled because Party State uses the
  module's explicit revision and conflict policy.
- REF-001 now owns consolidation of targeted Party Sheet rerenders.

No design-document change was required. No now-unused code remains.
