# PB-007 — Verify ApplicationV2 integration

Status: `DONE`

Completed: 2026-08-14

## Implemented outcome

Established a shared ApplicationV2 contract that works in Foundry 13.351 and
14.365 using HandlebarsApplicationMixin, parts/templates, declarative actions,
explicit rerender, stable singleton references, and clean close behavior.

  lifecycle and publishes structured results.
- `tests/foundry/diagnostics/templates/diagnostic-app.hbs`: Provides the
  parts/template and action target used by the runtime check.
- `HYP3E-UTILITIES-DESIGN.md`: Records the validated cross-version contract.
- `docs/compatibility-notes.md`: Records both supported Foundry results.

## Automated verification

- `npm run check` syntax-checks the diagnostic module and validates its test
  manifest.

- A declarative action ran and rerendered updated context.
- An explicit rerender succeeded.
- The application reference remained stable across all three renders.
- Closing removed the rendered application cleanly.
- Every assertion passed in Foundry 13.351 and 14.365.
