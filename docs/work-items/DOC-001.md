# DOC-001 — GM and Player User Documentation

## Implemented outcome

Added a release-ready operator guide that takes a new tester from installation
through every core GM and Player workflow without relying on development notes.

The guide covers:

- public-manifest and private-ZIP installation;
- first-time GM setup and managed-treasury initialization;
- role-threshold and explicit-user Party Sheet permissions;
- NPC Action HUD selection, rolls, positioning, and reset;
- every Party Sheet tab, drafts, and keyboard navigation;
- XP, coin, and GP-wage preview/writeback semantics;
- bidirectional supported Item transfers;
- recovery and troubleshooting; and
- the complete current limitation set and a new-world acceptance checklist.

The README is now a concise release landing page and links directly to the
guide.

  installation for pre-publication testing.
